Some commands of OpenDucktor have default keys, and you can change them. You can also give keys to most other commands, such as a workflow action.

<ProductDemo id="keyboard-shortcuts" />

## Open a session by its position [#positions]

Hold <kbd>Cmd</kbd> on macOS or <kbd>Ctrl</kbd> on Windows and Linux. Each session of the sidebar and each workspace of the workspace rail shows its key.

- Press a number from <kbd>1</kbd> to <kbd>0</kbd> to open the session at that position.
- Add <kbd>Shift</kbd> to open the workspace at that position.

## Change a shortcut [#change]

<Steps>
<Step>Open [**Settings**](/settings-reference/#open-settings), then **Keyboard shortcuts**.</Step>
<Step>In **Search commands**, type the name of the command or its keys.</Step>
<Step>Select the keys of the command, or **Add keys** if it has none. Then press the new keys.</Step>
<Step>If another command uses these keys, select <Action>Replace</Action> to move the keys, or <Action>Record other keys</Action>.</Step>
<Step>Select <Action>Save settings</Action>.</Step>
</Steps>

The command shows the **Custom** badge. For the other options of each command, see [Keyboard shortcuts](/settings-reference/#keyboard-shortcuts) in the Settings reference.

## Fixed keys [#fixed-keys]

You cannot change these keys.

### Composer [#fixed-composer]

| What it does | Keys |
|---|---|
| Sends the message, or queues it while the agent works. See [Queue a message](/coding-sessions/#queue). | <kbd>Enter</kbd> |
| Steers the message into the running turn. [Steer messages by default](/settings-reference/#chat-steer-messages-by-default) swaps it with <kbd>Enter</kbd>. | <kbd>Cmd</kbd>+<kbd>Enter</kbd> on macOS, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> on Windows and Linux |

### Command palette [#fixed-palette]

| What it does | Keys |
|---|---|
| Runs the main action of the selected task. | <kbd>Cmd</kbd>+<kbd>Enter</kbd> on macOS, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> on Windows and Linux |
| Shows the actions of a task or a workspace session. <kbd>Right</kbd> works when the cursor is at the end of the search. | <kbd>Tab</kbd> or <kbd>Right</kbd> |
| In an action list with an empty search, goes back to the main list. | <kbd>Backspace</kbd> |
| Opens the workspace filter. | <kbd>Option</kbd>+<kbd>Down</kbd> on macOS, <kbd>Alt</kbd>+<kbd>Down</kbd> on Windows and Linux |
