- **Mark as Read** or **Mark as Unread**

- **Copy External Session ID**

## Answer the agent [#answer-pending-input]

<ProductDemo id="mobile-needs-you" />

<Screenshot id="phone-question" alt="The Spec session Show tag counts in the sidebar with an Input needed card: Should the sidebar show tags with zero notes? The agent recommends Hide empty tags. The card offers Hide empty tags, Show all tags, Other answer, Reset, and Confirm Answers.">

Tap a session under **Needs you**. It opens at the card that waits for you.

- **Approval required**: read the command, then tap <Action>Approve once</Action>, another approval, or <Action>Reject</Action>. The runtime of the session decides which approvals show. See [Coding sessions](/coding-sessions/#answer-a-permission-request).
- **Input needed**: tap an answer, or <Action>Other answer</Action>. With more than one question, tap <Action>Next</Action> after each answer, then <Action>Review Answers</Action> and <Action>Confirm Answers</Action>.

A **Blocked** task opens its latest session, or its task details. After your answer, the session moves to **Running**.

## Send and steer messages [#messages]

<ProductDemo id="mobile-steer" />

While the agent works, you choose when it reads your message:

- **Send** queues the message. The agent reads it when its turn ends.
- **Steer**, the lightning button next to **Send**, gives the message to the agent in the running turn.
- **Queued messages** show above the composer. Tap the stack, then <Action>Steer now</Action>, <Action>Edit</Action>, or <Action>Remove</Action>.
- <Action>Stop session</Action> stops the turn.

With [Steer messages by default](/settings-reference/#chat-steer-messages-by-default) on the host, **Send** steers and the small button queues.

### Follow a goal [#goal]

When the Builder works in [Goal mode](/coding-sessions/#goal-mode), the goal row shows above the composer: **Goal**, the status, the objective, and icon buttons to pause, resume, or clear the goal. Tap the objective to read the whole goal.

- To set or change a goal, send `/goal` with the objective, or `/goal pause`, `/goal resume`, or `/goal clear`. The message shows a **Goal** chip.
- While a goal drives the work, your other queued messages wait until the goal stops.

## Start a session [#new-session]

Tap <Action>+</Action> in the tab bar, then <Action>New Session</Action>. A new session is a [workspace session](/workspace-sessions/): it belongs to no task.

<Screenshot id="phone-new-session" alt="The New session sheet with Workspace, Name, Runtime and model, Effort, Custom role, and Work location with Current checkout selected, and the Cancel and Create session buttons.">

<Steps>
<Step>Choose the **Workspace**. Type a **Name**, or leave it empty for a generated title.</Step>
<Step>Choose the **Runtime and model** and the **Effort**. A **Custom role** gives the agent the instructions of that role. You add custom roles on the desktop.</Step>
<Step>Choose the **Work location**: **Current checkout**, **New worktree**, or **Existing worktree**. For **Existing worktree**, choose the **Worktree**. For **New worktree**, choose **Existing branch** or **New branch**, then type the **Worktree name**. **New branch** also takes an optional **Branch name**.</Step>
<Step>Choose the **Target branch**. **Changes** compares the session with it.</Step>
<Step>Tap <Action>Create session</Action>.</Step>
</Steps>

</Screenshot>

## Fork, rename, and archive [#manage]

- **Fork**: tap the fork icon under a reply of the agent, **Fork from this reply**. A workspace session asks where the copy works: **Same folder** or **New worktree**. A task session forks at once.
- **Rename**: long press a workspace session, then **Rename Session**. Leave the name empty to use the generated title.
- **Archive**: long press a workspace session, then **Archive Session**. For a session in its own worktree, **Remove worktree and branch** is on by default.
- **Restore**: tap **Archived Sessions**, the archive button at the top of the **Sessions** tab. Then tap <Action>Restore</Action> next to a session. If its worktree was removed, the restore makes it again from the target branch of the session. An archived session opens read-only, with <Action>Restore Session</Action>.
